# 00. Project Brief

## 目的

日本国内で安く仕入れ、海外で高く売れる商品を探す作業を、感覚ではなくデータで行う。

本システムは、自動で商品を購入するものではない。候補を抽出し、仕入判断に必要な根拠を一画面または一CSVへ集約する。

## 解決する問題

商品価格差だけを見て仕入れると、国際送料と手数料で赤字になる。以下を一元化する。

- 国内価格
- 海外販売価格
- 販売数
- 競合数
- 送料
- eBay手数料
- 広告費
- 関税・通関費
- 返品リスク
- 商品重量
- 規制
- 原産国
- 継続仕入れ可否

## 対象利用者

- 日本在住の小規模越境EC事業者
- 初期資金3万〜10万円程度
- eBayを最初の販売先とする
- AI・自動化を活用したい
- 既存MySQLとVPSを利用したい

## MVP出力

- 国内最安仕入額
- 海外販売価格の根拠
- 推定国際送料
- 全費用
- 予想純利益
- 予想利益率
- 損益分岐販売価格
- 仕入資金効率
- 需要指標
- データ信頼度
- 判定
- 判定理由

## 判定種類

| 判定 | 意味 |
|---|---|
| `BUY_TEST_1` | 1個だけテスト仕入れ候補 |
| `BUY_TEST_2` | 最大2個までテスト候補 |
| `WATCH` | 価格変化を監視 |
| `NEEDS_RESEARCH` | 販売済みデータ等が不足 |
| `REJECT_LOW_PROFIT` | 利益不足 |
| `REJECT_LOW_DEMAND` | 需要不足 |
| `REJECT_RISK` | 規制・真贋・危険物等 |
| `REJECT_STALE_DATA` | データが古い |
| `BLOCK` | 扱わない |

## 非目標

- 商品の自動購入
- eBayへの自動出品
- Product Researchへの自動ログイン
- CAPTCHA回避
- 食品、化粧品、医薬品、危険物の自動承認
- AIによる最終規制判定

## 成功指標

- CSV取込100件をエラーなく処理
- 利益計算が手計算と1円以内で一致
- 同じ入力なら同じ結果
- API障害時も過去データで再計算可能
- 1候補の計算根拠を追跡可能
- 上位10件だけProduct Researchで確認できる
