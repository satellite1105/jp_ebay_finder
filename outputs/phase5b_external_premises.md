# Phase 5B — 外部前提調査サマリー

作成日: 2026-08-09
方法: research-loopフェーズ2〜3準拠。WebSearchで独立複数ソースを収集し、一次情報(eBay公式ヘルプ/Developer Program、日本税関、国税庁、eBayコミュニティ上の公式ページ引用)を優先。詳細な主張ごとの出典・取得日は `outputs/research_notes.md` を参照。

**重要な留保**: eBay公式手数料ページ(ebay.com/help/selling/fees-credits-invoices/selling-fees)への直接WebFetchは複数回タイムアウトし、本文を直接取得できなかった。以下の数値は独立した3つ以上の二次情報ソース、および同ページを引用しているeBayコミュニティフォーラム投稿の一致に基づく「準一次情報」であり、完全な一次情報検証ではない。今後可能であれば、実際にeBayセラーアカウントにログインして公式Fee tableページを直接確認することを推奨する。

---

## 1. eBay Final Value Fee（標準率）
- 標準カテゴリのFVFはおおむね13.6%(2025年2月改定後)。Store非加入セラーは13.25%(〜$7,500部分)+超過分2.35%。Basic Store以上は12.35%。
- 注文ごとの固定手数料: $10以下の注文は$0.30、$10超は$0.40。
- **分類: verified**（複数独立ソース一致。ただし直接一次情報フェッチ未達のため準一次情報）。**同時に「時間とともに変わる値」であることも確認済み**(2025年2月に実際に改定実績あり)。コードへの固定埋め込みは不可、config管理＋定期更新が必須。

## 2. カテゴリ別FVF差
- Electronics: 13.25%(非Store)/12.35%(Basic Store以上)。Collectibles & Fine Art: 15%/14%。Trading cards・一部collectibles: 13.25%+per-order。全体レンジは2.5%〜15.3%。
- **分類: user/business-specific**。出品カテゴリ構成に強く依存し単一値化できない。カテゴリ別feeテーブルとしてconfig側で複数プロファイルを持つ設計が妥当（`config/fee_profiles.example.yaml`の設計思想と整合）。

## 3. 越境販売の追加手数料(International Fee)
- バイヤー登録住所または配送先が米国外の場合、取引総額の1.65%が標準FVFに加算される。米国登録セラーがeBay International Shipping対象リスティングを使う場合は課されない。
- 日本登録のeBayグローバルセラーは、直近2ヶ月合計売上が$3,000以上の場合、国際決済手数料の月次ボリュームディスカウントを受けられる。
- **分類: 1.65%自体は verified 相当（複数独立ソース一致）。ボリュームディスカウントの適用有無は user/business-specific**（アカウント売上実績依存）。本ツールがJP発送・海外バイヤー前提である以上、International Feeを既定の利益計算に含めるべきかは要検討（現在の実装が含めているかはPhase 5Aの監査結果と突き合わせる）。

## 4. Promoted Listings(広告費)
- 成果報酬型。セラー任意設定のad rate(下限は2023年7月に1%→2%へ、2024年12月以降のDynamic Ad Rate Capモデルでは最低5%へ引き上げ済み。上限100%、実勢2〜15%)を、広告経由で30日以内に成約した取引総額に乗じて課金。売れなければ費用なし。
- **分類: verified**(仕組みはeBay公式ヘルプ/Developer Programで確認。下限%はfact-checkerによる独立検証で訂正済み — 旧「1%〜100%」表記は誤り)。ただし**利用有無・料率はセラーの任意選択**であるため、デフォルトの利益計算に強制的に組み込むべきではない。使う場合はオプトインのconfig項目として扱うのが妥当。

## 5. 為替レートの運用慣行
- ミッドマーケットレート(仲値)自体は無手数料の理論値。実際の両替・決済ではプロバイダが2.5〜4.5%程度のスプレッドを上乗せするのが一般的。国際プロジェクトの財務モデルでは3〜5%程度の「不利側シャドーレート」を使う実務例がある。
- **分類: unverifiable as universal constant**。公式に固定された「為替バッファ率」は存在しない。3〜5%は実務プラクティスの一例に過ぎず、configurable assumptionとして扱うべきで、コードへの固定値埋め込みは不適切。

## 6. 日本から米国への国際送料
- 日本郵便EMS 1kg小包は2026年1月時点で米国向け¥5,300(参考値)。2026年に米国向け郵便物の一時停止・再開(2026年4月13日)という運用変動が実際に発生している。
- **分類: unverifiable as universal constant**。重量・サイズ・配送業者(EMS/国際小包/民間キャリア)・宛先国・時期(運行停止・燃油サーチャージ改定等)に強く依存し、普遍定数化できない。CSV/config経由での実勢値の都度投入が妥当な設計であり、コードに固定送料を埋め込むのは誤り。

## 7. 返品率・返品引当の公式固定値
- eBayのTransaction Defect Rate基準は「取引の2%以下」だが、これはキャンセル・MBG裁定・PayPal Purchase Protection裁定等を含む「欠陥率」であり、返品率そのものの公式固定値ではない。
- **分類: user/business-specific(またはunverifiable as universal constant)**。「利益計算に使うべき返品率」としてeBayが定める固定値は存在しない。ユーザーが自身の実績に基づきconfig側で設定すべき値であり、根拠のない数値をデフォルトとして埋め込むべきではない。

## 8. 税関・関税(customs / de minimis)
- 2025年8月29日以降、米国向け商業貨物は価格を問わず正式税関申告・関税支払いの対象となり、従来の$800以下免税(de minimis, Section 321)は事実上廃止(2026年6月に恒久規則化)。2026年7月24日以降、$2,500以下の国際郵便輸入には新たな簡易申告プロセスが適用。
- **分類: 制度変化自体はverified（一次情報＝CBP規則動向を引用する複数独立ソース一致）。個々の品目にかかる実際の関税額はHTSコード依存でuser/business-specific・ツールの自動算出範囲外。**
- **重要**: この変化は本ツールの前提に直接影響する。「低額品は関税なしで輸出できる」という旧来の一般的想定は、少なくとも現時点(2026年8月)の米国向けについては成立しない。利益計算・判定ロジックが暗黙に旧de minimis前提を置いている場合は要注意（Phase 5Aの監査結果と突き合わせて確認）。

## 9. 日本の消費税(輸出免税)
- 日本の消費税法上、輸出取引は免税(0%)。ただし課税事業者であることや、EMS等追跡可能な発送方法での証跡が要件。
- **分類: verified**(日本税関・国税庁公式情報で確認)。個々の事業者が課税事業者かどうかはuser/business-specific。

## 総括: 分類別まとめ

| 項目 | 分類 | 単一定数としてコード/デフォルト埋め込み可否 |
|---|---|---|
| eBay標準FVF(~13.6%目安) | verified(準一次情報) | 不可。config管理＋定期更新必須 |
| カテゴリ別FVF差 | user/business-specific | 不可。カテゴリ別プロファイルが必要 |
| International Fee(1.65%) | verified(準一次情報) | configとしてなら可(ただし要否要判断) |
| Promoted Listings広告費 | verified(仕組みのみ) | 不可(任意オプトイン項目) |
| 為替バッファ率 | unverifiable as universal constant | 不可 |
| 国際送料(JP→US) | unverifiable as universal constant | 不可。CSV/実勢値運用が必須 |
| 返品率 | user/business-specific | 不可 |
| 関税(de minimis変化) | 制度変化はverified、税額自体はuser/business-specific | 不可。前提の明記のみ可能 |
| 日本消費税輸出免税 | verified | 参考情報として明記可 |

**根拠のない数値を「最新の正解値」として使わないこと**という指示に従い、上記のうちverifiedと明記した項目以外は、config内のデフォルト値をあくまで「例示・仮定値」として扱い、本番運用前にユーザー自身の実績・契約条件に基づく更新が必要である旨を明示する。
